Response-surface optimization.

This module locates the factor settings that maximize, minimize, or achieve a target value of a fitted doe_model response surface within a box of factor bounds. The search is performed in coded variables on the range [-1, 1], which is the scale on which the model is assumed to have been fit, using a projected gradient method with a backtracking line search that is started from multiple points to reduce the chance of stopping at a local optimum.

The maximum number of iterations allowed for each starting point. The default is 1000.

A doe_optimization_result containing the optimal factors in both coded and natural scale, the predicted response at the optimum, the iteration count and convergence flag of the best run, the method name, and the tolerance used.
