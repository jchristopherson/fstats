DOE goodness of fit, residual analysis, comparison, and ANOVA.

The routines in this module operate on a fitted (or user-defined) doe_model and the data used to evaluate it. In each case, the model is evaluated at the M-by-N factor matrix X using doe_evaluate_model, and the result is compared with the M observed responses Y. The factor values must be supplied in the same scale (e.g. coded on [-1, 1]) used when the model was fit.

The number of model parameters, , is taken as the number of coefficients enabled in the model's usage map (i.e. count(mdl%map)).
