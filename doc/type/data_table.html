procedure, public :: view => dt_view

  • private function dt_view(this, row_first, row_last, column_first, column_last) result(rst)

    Creates a live view using optional one-based row and column bounds. Bounds are reapplied to current positions and clipped to the current table shape, so structural edits can change the selected values. Omitted final bounds expand as rows or columns are appended; explicit final bounds remain fixed.

    Arguments

    Type IntentOptional Attributes Name
    class(data_table), intent(inout) :: this

    The source table whose shared state is retained.
    integer(kind=int32), intent(in), optional :: row_first

    First selected row; defaults to one.
    integer(kind=int32), intent(in), optional :: row_last

    Inclusive final row; omitted means through the current final row.
    integer(kind=int32), intent(in), optional :: column_first

    First selected column; defaults to one.
    integer(kind=int32), intent(in), optional :: column_last

    Inclusive final column; omitted means through the current final column.

    Return Value type(data_table_view)

    The live positional view.
